# pushArg Finanzas - Frontend Application

Repositorio Frontend oficial de **pushArg Finanzas** (React + Vite + Tailwind CSS + Lucide Icons + Recharts).

Consulta el documento de contexto general en la raíz del proyecto para más detalles de arquitectura y despliegue:
`CONTEXTO_PROYECTO_PUSHARG_FINANZAS.md`

## Comandos Rápidos
```bash
npm install
npm run dev      # Servidor local en http://localhost:3000
npm run build    # Compilación de producción
```
